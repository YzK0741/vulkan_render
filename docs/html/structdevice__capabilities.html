Detailed Description

Note
  • query() builds the pNext chains from the requested api_version and issues vkGetPhysicalDeviceFeatures2 + vkGetPhysicalDeviceProperties2 in one pass
  • after query(), features stay enabled where the driver supports them (except the deliberately disabled ones), so the struct is directly usable for vkCreateDevice
  • device_pnext() returns the feature chain head to pass via device_creation_info::pNext
